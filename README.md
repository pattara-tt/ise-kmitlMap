# KMITL MAP

ระบบแผนที่และนำทางภายในสถาบันเทคโนโลยีพระจอมเกล้าเจ้าคุณทหารลาดกระบัง

## วิธีรัน

1. ติดตั้ง [Node.js](https://nodejs.org) เวอร์ชัน 18 ขึ้นไป
2. ติดตั้ง dependency: `npm install`
3. รัน dev server: `npm run dev`
4. เปิดเบราว์เซอร์ไปที่ http://localhost:3000

> ไม่ต้องใช้ API key ใดๆ แล้ว (ตัดส่วน ORS / แชทบอทออกทั้งหมด)

## โครงสร้างไฟล์

```
app/
  page.jsx              เกตล็อกอิน + เมนูตาม Actor + shell
  layout.jsx            metadata / ฟอนต์ / Leaflet CSS
  api/auth/             UC27, UC28
  api/data/[name]/      CRUD กลางของทุก collection (+ บันทึก log UC3)
  api/stats/            UC1, UC14, UC20
  api/osm, api/walknet  ข้อมูลอาคาร/ทางเดินจาก OpenStreetMap
components/
  AuthPage.jsx          UC27, UC28
  UserApp.jsx           UC23–UC26
  panels/*.jsx          UC1–UC22, UC29 แยกตาม Actor
  MapView.jsx           แผนที่ + ผังชั้นในอาคาร + นำทาง
  mapConstants.js       พิกัด/ขอบเขต/กราฟ node-edge ของอาคาร Sc8
  mapGeo.js             ฟังก์ชันคำนวณเส้นทาง (Dijkstra) และ geocoding
  mapBaseLayer.js       เรนเดอร์แผนที่พื้นสไตล์ Google Maps
  ui.jsx                ชุด UI กลาง + hook เรียก API
lib/
  store.js              mock database (in-memory)
  usecases.js           สารบัญ Use Case ต่อ Actor
public/data/            ผังชั้น SVG / ไอคอน / ภาพอาคาร (คงเดิม)
```

## หมายเหตุ

- ส่วนที่ไม่อยู่ในขอบเขต KMITL MAP ถูกลบออกแล้ว ได้แก่ ระบบเดินกลางคืน/ไฟส่องสว่าง (streetlight, จุดมืด), การคำนวณร่มเงา/แดด, ข้อมูลน้ำท่วมและ Traffy Fondue, กล้อง CCTV, โหมดนำทาง 3D และแชทบอท AI
- `lib/store.js` เป็นฐานข้อมูลจำลองในหน่วยความจำ ข้อมูลจะรีเซ็ตเมื่อรีสตาร์ทเซิร์ฟเวอร์ — ผลิตจริงให้เปลี่ยนไปต่อฐานข้อมูลจริงโดยคง interface `list/insert/update/remove` เดิม
